## [1.0.0a6] - 2026-04-10

### Added
- Initial public alpha release as open source project
- Support for test case set reviews use case
- Support for test case set descriptions use case
- Support for defect explanations use case
- Pluggable LLM provider architecture with OpenAI implementation
- YAML-based configurable prompt templates with Jinja2 support
- Per-project language and LLM configuration overrides
- Built-in Swagger UI at `/docs`
- SSL/TLS support with optional mTLS
- Trusted reverse proxy configuration
- CLI commands: `init`, `start`
- German and English locale support
